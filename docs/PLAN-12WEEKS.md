# خطة Arabic Medical RAG — 12 أسبوعًا

## القاعدة الأولى قبل أي شيء

**هذا المشروع يُبنى على 4 مستودعات فقط. الباقي يُجمَّد.**

```
أصول مشروعك (4):
├── ocr-core                        ← التبعية التقنية
├── arabic-medical-glossary         ← 470K مصطلح
├── arabic-medical-ocr-corrections  ← 319 تصحيح (HF)
└── medical-rag-ar                  ← المشروع الجديد (هذا ما نبنيه)
```

**يُجمَّد لمدة 12 أسبوعًا**:
- `marathon_ted_pipeline` (أرشفة للعرض)
- `tg-campaign-toolkit` (يبقى خاص)
- `omni-medical-suite` (أرشفة — البنية موجودة في rag-ar)
- `intelli-file-manager` (يبقى واجهة `medical-rag-ar` لاحقًا)
- 35 مستودعًا آخر → أرشفة/دمج

## المعمارية النهائية

```
┌─────────────────────────────────────────────────────────┐
│  medical-rag-ar (المشروع الجديد)                        │
│                                                          │
│  ┌────────────┐   ┌──────────────┐   ┌──────────────┐  │
│  │ Ingestion  │──→│  Retrieval   │──→│  Reasoning   │  │
│  │            │   │              │   │              │  │
│  │ PDF/صور    │   │ BM25 + dense │   │ Qwen 2.5 7B  │  │
│  │ ↓          │   │ + RRF        │   │ (محلي)       │  │
│  │ ocr-core   │   │              │   │              │  │
│  │ ↓          │   │ Qdrant/FAISS │   │ + guardrails │  │
│  │ chunking   │   │              │   │              │  │
│  │ ↓          │   │              │   │              │  │
│  │ embeddings │   │              │   │              │  │
│  └────────────┘   └──────────────┘   └──────────────┘  │
│                                                          │
│  ┌────────────────────────────────────────────────────┐ │
│  │  Evaluation (500 سؤال/جواب طبي عربي)              │ │
│  └────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────┘
```

**المكونات التقنية**:

| الطبقة | الاختيار | السبب |
|--------|---------|------|
| OCR | `ocr-core` (Tesseract + Paddle) | موجود، يعمل |
| Embeddings | `BAAI/bge-m3` أو `aubmindlab/bert-base-arabertv2` | عربي جيد، مفتوح |
| Vector store | Qdrant (محلي) | سريع، Python-first |
| LLM | Qwen 2.5 7B Instruct (محلي) | الأفضل للعربية حاليًا |
| Retrieval fusion | RRF (Reciprocal Rank Fusion) | دمجة BM25 + dense |
| الواجهة | Gradio (HF Space) + Next.js لاحقًا | سرعة الإطلاق |
